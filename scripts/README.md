# Scripts

The supplied Cisco exercise is performed primarily in Scapy's interactive shell. This folder is reserved for optional Python scripts you write yourself to reproduce or extend the lab in an authorized environment.

Before adding a script:
- Include a short purpose and usage description.
- Make target addresses and interfaces explicit and configurable.
- Keep packet sending disabled by default until the operator reviews the target and authorization.
- Do not include credentials, private keys, or captured private traffic.
