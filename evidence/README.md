# Evidence

Add only evidence generated from your own authorized lab.

- `screenshots/`: screenshots grouped by lab part.
- `terminal-outputs/`: cleaned text outputs that support your findings.
- `pcaps/`: packet captures. PCAP files are ignored by Git by default because they may contain sensitive traffic. Publish only a reviewed and sanitized capture when you have permission.

Before publishing, inspect screenshots and outputs for usernames, credentials, public IPs, personal data, and unrelated traffic.
